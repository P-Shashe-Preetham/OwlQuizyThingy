# Design System

## Overview
The design system for OwlQuizThingy uses Tailwind CSS (`@tailwindcss/vite` V4) with a custom theme defined in `src/index.css`.

## Tokens
- **Primary Color:** `#ff9900`
- **Secondary Color:** `#1a140b`

## Principles
- Consistent styling using Tailwind classes.
- Accessible contrast for all interactive elements.
- Reusable UI primitives located in `src/shared/components`.
