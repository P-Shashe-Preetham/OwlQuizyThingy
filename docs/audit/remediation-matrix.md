# OwlQuizThingy Comprehensive Remediation Matrix

| ID | Workstream | Vulnerability / Issue Description | Severity | Root Cause | Remediation Target | Verification Strategy |
| --- | --- | --- | --- | --- | --- | --- |
| **SEC-01** | Security | Hardcoded manager password (`admin123`) in configuration files and fallback code. | Critical | Hardcoded fallback in `render.yaml`, `.env.example`, and `Config.game()`. | Remove password defaults; require secure environment variable injection; document rotation. | `pnpm test`, config unit tests, credential scan. |
| **SEC-02** | Security | Unauthenticated Socket.IO manager event execution. | Critical | Manager handlers rely on `withGame()` without checking socket authentication session. | Enforce server-side `isAuthenticatedManager()` guard on every manager socket event. | Unit & Socket contract tests. |
| **SEC-03** | Security | Unvalidated Socket.IO client event payloads. | High | Socket event payloads passed directly to logic without runtime type checking. | Implement Zod schema validation for all client-to-server events. | Unit tests sending malformed payloads. |
| **SEC-04** | Security | Wildcard CORS origin (`*`) on WebSocket server. | High | Default fallback in `packages/socket/src/index.ts`. | Restrict CORS to explicitly configured `CORS_ORIGIN` env var. | Socket connection contract tests. |
| **SEC-05** | Security | Lack of Socket.IO event rate limiting and payload size limits. | Medium | Unlimited message frequency and payload size allowed. | Add rate limiting and payload length guards. | Contract tests for rate limit bounds. |
| **ENG-01** | Game Engine | Missing formal game state machine and loose phase checks. | High | Game logic relies on scattered booleans (`started`, `cooldown.active`). | Implement explicit `GameState` enum and transition guards in `Game` class. | Game state machine unit tests. |
| **ENG-02** | Game Engine | Answer submission allowed outside active question phase. | Critical | `selectAnswer` does not strictly enforce question timing or state. | Validate current phase is `SELECT_ANSWER` and submission time is within round bounds. | Concurrent timer & answer submission tests. |
| **ENG-03** | Game Engine | Timer leakage and overlapping round transitions. | High | `sleep()` promises and timers run without cancellation on abort or game destroy. | Add timer cancellation tokens / generation guards on round state transitions. | Integration test simulating game abort mid-question. |
| **ENG-04** | Game Engine | Player identity collision on disconnect/reconnect. | Medium | Active and disconnected player lists allow duplicate usernames or socket hijacking. | Enforce distinct active vs disconnected player identity semantics in `Game` and `Registry`. | Reconnect integration tests. |
| **PER-01** | Persistence | Firebase document ID overwritten by internal quiz `id`. | High | `{ id: doc.id, ...doc.data() }` allows payload `id` to override canonical Firestore document ID. | Enforce canonical `doc.id` during read/normalization and maintain document identity on edit. | Firebase service unit tests with mock Firestore. |
| **PER-02** | Persistence | Editing existing quiz generates a new UUID on save. | High | `saveQuizz` generates `uuid()` when ID parameter is lost or omitted by client. | Preserve quiz ID across creator edit and save flows. | End-to-end quiz save/edit test. |
| **PER-03** | Persistence | Single malformed local quiz JSON invalidates entire quiz collection. | Medium | Uncaught JSON parsing error or validation failure halts quiz loading loop. | Wrap individual quiz file reads in try/catch and log malformed files safely. | Local quiz loader unit tests with invalid JSON fixture. |
| **FED-01** | Frontend | Local quiz draft cleared immediately after emitting `manager:saveQuizz`. | Medium | UI clears draft state speculatively before receiving server acknowledgement. | Wait for `manager:quizzSaved` socket event before clearing local draft state. | Playwright E2E creator test. |
| **FED-02** | Frontend | Unprotected manager routes accessible without session. | Medium | Client router allows navigation to `/game/party/manager` without manager authentication state. | Add route navigation guards redirecting unauthenticated users to `/game/auth/manager`. | Router unit & E2E navigation test. |
| **FED-03** | Frontend | Non-semantic clickable divs and missing ARIA accessibility. | Medium | Buttons and interactive controls lack keyboard focus and screen reader attributes. | Refactor buttons, inputs, and modals to use semantic HTML and proper ARIA labels. | Axe / Playwright accessibility scan. |
| **INF-01** | Infrastructure | Docker Compose references upstream image `ralex91/rahoot:latest`. | High | `compose.yml` deploys external third-party image rather than repository source. | Update `compose.yml` to build local `Dockerfile`. | `docker compose config` & `docker build`. |
| **INF-02** | Infrastructure | Inconsistent port mapping and missing container health checks. | Medium | `Dockerfile` and `render.yaml` hardcode ports and lack health check definitions. | Align `PORT` environment variable handling, create `/health` endpoint, and add container healthchecks. | Container smoke test & curl `/health`. |
| **TST-01** | Testing | Complete lack of unit, integration, contract, and E2E testing framework. | High | Zero test scripts or test files in repository root or packages. | Configure Vitest, Playwright, and write regression test suites for all target issues. | `pnpm test` and `pnpm test:e2e`. |
| **CIC-01** | CI/CD | Missing PR quality gates and automated security scanning. | Medium | No GitHub Actions workflows exist for linting, testing, or security scanning. | Add `.github/workflows/ci.yml` running lint, typecheck, unit tests, security scans, and build. | Trigger workflow / local workflow dry run. |
